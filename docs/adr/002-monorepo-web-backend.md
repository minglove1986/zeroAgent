# ADR-002：前后端同仓 Monorepo

- 状态：已采纳  
- 日期：2026-07-21  
- 决策人：产品确认
- 后续修订：`ADR-003` 自 2026-07-29 起增加同仓独立管理端 `admin-web/`；本 ADR 的单仓原则继续有效

## 背景

需明确前端落地位置：同仓 `web/` 还是独立仓库。系统交由 AI Agent 开发，接口与对话页强耦合。

## 决策

采用 **同仓 monorepo**：

- 后端：`src/app`（FastAPI）  
- 前端：`web/`（Next.js + React Flow）  
- 不另开前端仓库（D34）

## 后果

- AI 单仓上下文，契约不易漂移。  
- 本地：API `:8000`，Web `:3000`（代理/CORS）。  
- 未来若需独立发版，再拆 `web/` 为独立仓。
