# ADR-001：单租户、文档现行唯一真相、Web 对话主入口

- 状态：已采纳（v0.7.4 修订）  
- 日期：2026-07-21  
- 决策人：产品确认  

## 背景

仓库由 AI Agent 实现；多文档演进易导致实现多租户、外部 A2A、Agent 绑工具、强绑 OpenIM、OSS 事件入库等废止方案。

## 决策

1. **单租户**，不做 `tenant_id`。  
2. PRD 第十六章（D1–D33）+ API/库表为唯一实现源；附录与 closure-design 史料废止。  
3. **不接入 OpenIM**；Web 系统对话 + 交互卡片；提问经技能 **`ask_user`**；文件 Web 上传入库。  
4. 开发：LiteLLM 本地；LLM/OSS 线上。

## 后果

- 实现边界清晰，适合 Agent 执行。  
- 未来多租户或 IM 通道须新 ADR，不得静默加入。
