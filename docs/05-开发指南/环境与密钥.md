# 环境与密钥（一页纸）

> 2026-07-21 | AI Agent / 本地开发

## 1. 快速启动

```bash
cp deploy/.env.example deploy/.env
# 无真实 Key 时保持 MOCK_EXTERNAL=true
docker compose -f deploy/docker-compose.yml up -d
cd /d/HermesWork/zeroAgent   # 或你的仓库根
pip install -e ".[dev]"      # 或 pip install -r requirements.txt
uvicorn app.main:app --app-dir src --reload --port 8000
pytest -q
```

## 2. 关键变量

| 变量 | 说明 | 本地建议 |
|---|---|---|
| `MOCK_EXTERNAL` | `true` 时不调真实 OpenIM/OSS/LLM | 无 Key 时必须 true |
| `DATABASE_URL` | MySQL | compose 内 `mysql:3306` |
| `REDIS_URL` | Redis | compose |
| `RABBITMQ_URL` | AMQP | compose |
| `LITELLM_PROXY_URL` | `http://localhost:4000` | compose 服务 `litellm` |
| `LITELLM_MASTER_KEY` | Proxy 密钥 | 与 compose 一致 |
| `OPENAI_API_KEY` 等 | 线上模型（给 LiteLLM） | 可空（Mock） |
| `STORAGE_BACKEND` | `oss`（推荐）或 `minio` | 开发默认 oss |
| `OSS_*` | 线上 Bucket（含 `OSS_PUBLIC_BASE_URL`） | Mock 时可空；密钥勿提交仓库 |
| `OPENIM_*` | **本阶段不用**（D27 不接入 OpenIM） | 可忽略 |
| `LANGFUSE_HOST` | **自托管** | `http://localhost:3100`，禁止 Cloud |
| `APP_SECRET_KEY` | Session 签名 | 随机长串 |

## 3. 外置依赖

| 依赖 | 谁提供 | 失败时 |
|---|---|---|
| OpenIM | **不接入** | 勿启动、勿实现回调 |
| LiteLLM | Compose | 必须起；上游 Key 可空 |
| OSS | 线上 | Mock 写本地 `./.data/oss` 或跳过实际上传 |
| LLM | 线上经 LiteLLM | Mock 返回固定文本流 |

## 4. 文件入库

主路径：**Web 上传 / API → 服务端写 OSS → Celery**。  
**不要**实现 OpenIM `file-callback`；不要以 OSS 桶事件作为主路径。
