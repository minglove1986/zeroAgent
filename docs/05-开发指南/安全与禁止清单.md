# 安全与禁止清单

> 2026-07-21 | AI Agent 实现时逐条遵守

## 禁止

1. 硬编码密码、API Key、OSS Secret、OpenIM Secret  
2. 业务代码直连 OpenAI/通义等厂商 SDK（必须经 LiteLLM Proxy）  
3. 使用 `https://cloud.langfuse.com` 作为默认 Trace  
4. 表结构或中间件引入 `tenant_id` / 多租户隔离  
5. Agent API/模型接受一等字段 `tool_ids`  
6. Agent 运行时直接 FC 原子 HTTP/DB/文件工具  
7. 外部 A2A Server/Client  
8. **任何 OpenIM 集成**（同步/机器人/file-callback/卡片）及自助绑工号  
9. 以 OSS 桶事件作为文件入库主路径（现行：Web 上传 → OSS → Celery）  
10. 部门管理员接口实现「启停用户 / 改角色 / 系统配置」  
11. 把 PRD 附录 A 史料当需求实现  
12. `eval` / `exec` 执行用户输入；未知 pickle 反序列化  

## 必须

1. 密码哈希存储（如 bcrypt/argon2）  
2. 高风险工具：`approval_tasks` + 超时  
3. 日志 PII 脱敏  
4. Session HttpOnly；生产 HTTPS  
5. API Key 哈希存储，明文仅创建时返回一次
