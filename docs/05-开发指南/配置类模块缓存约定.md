# 配置类模块缓存约定（MySQL + Redis）

> 状态：现行工程约定  
> 日期：2026-07-29  
> 作者：赵振明  

## 适用范围

管理员可改、运行时**高频读取**的设置 / 词表 / 白名单 / 枚举配置，例如：

- L2 意图关键词（`intent_l2_keywords`）
- 记忆抽取字段白名单（`memory_extract_fields`）
- 系统人格提示词（`system_persona_settings`）
- 后续同类「设置模块」

## 硬约束

1. **MySQL = 唯一真相源**（单租户，禁止 `tenant_id`）  
2. **服务启动**必须全量加载到 Redis  
3. **业务热路径只读 Redis**；禁止每请求打配置表  
4. **管理增删改**：先成功写库，再刷新缓存；刷失败须可观测，并提供 `reload-cache`  
5. **禁止**以 Redis 数据回写 MySQL  
6. Redis/DB 皆不可用时：允许进程内 DEFAULT_SEED 降级，并打 `degraded` 标记  

## 推荐结构

```text
MySQL (config table)
    │ 启动 / CRUD 后
    ▼
Redis  za:<domain>:<name>:v1  (+ :ver)
    │ 热路径
    ▼
get_xxx_catalog() → 业务匹配 / prompt
```
