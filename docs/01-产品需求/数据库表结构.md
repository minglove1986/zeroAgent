# zeroAgent 数据库表结构（现行 · AI Agent 实现源）

> 版本 v0.7.4 | 2026-07-21 | MySQL 8.0  
> **唯一实现依据**。单租户：**禁止** `tenant_id`。  
> 对齐 PRD v0.7.4：Web 对话 + message_cards + ask_user；**不建** OpenIM 映射表。

---

## 0. 约定

| 项 | 值 |
|---|---|
| 字符集 | utf8mb4 |
| ID | 业务前缀 + ULID/随机串（`usr_` `agt_` `skill_` …） |
| 软删 | `deleted_at` |
| 时间 | DATETIME UTC |

---

## 1. 表清单（现行）

| 表 | 用途 |
|---|---|
| users / departments / user_departments | 用户与组织 |
| roles / user_roles / role_permissions | RBAC（含 department_admin） |
| agents / agent_configs / agent_versions | Agent 与版本 |
| agent_skills / agent_kbs / agent_kgs / agent_callable_agents | Agent 绑定（**无 agent_tools 一等配置**） |
| skills / skill_versions / skill_tools | 技能与工具关联 |
| tools / tool_snapshots | 工具（不版本化，快照回滚） |
| knowledge_bases / kb_permissions / documents / document_qa_pairs / document_chunks | KB |
| workflows / workflow_nodes / workflow_edges / workflow_instances / workflow_node_executions | 工作流（实例含 dag_snapshot） |
| conversations / messages / message_feedbacks / **message_cards** | **Web 对话主入口 + 交互卡片** |
| notifications | 站内通知（告警/工作流通知节点） |
| user_memories | 用户记忆 |
| kg_ontologies / kg_entities / kg_relations | KG（图数据在 Neo4j，MySQL 元数据） |
| llm_providers / llm_models / prompt_templates | LLM 配置 |
| sensitive_words / usages / audit_logs_* / api_keys / caches | 安全用量审计 |
| approval_tasks | 高风险/人工确认（Web 待办） |
| alert_webhooks | 可选告警 Webhook |

> **废弃表（勿建）**：以 Agent 一等绑定为目的的 `agent_tools`、`agent_workflows`；**`im_user_maps`（本阶段不实现，未来 IM 通道再议）**。

## 2. 核心表 DDL

### 2.1 users / departments / user_departments

```sql
CREATE TABLE users (
  id VARCHAR(32) PRIMARY KEY,
  username VARCHAR(64) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  name VARCHAR(100) NOT NULL,
  employee_no VARCHAR(64) NOT NULL UNIQUE,
  email VARCHAR(255) NOT NULL,
  phone VARCHAR(32) NOT NULL,
  position VARCHAR(100) NOT NULL,
  hire_date DATE NOT NULL,
  main_department_id VARCHAR(32) NOT NULL,
  status ENUM('active','disabled') DEFAULT 'active',
  deleted_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE departments (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  parent_id VARCHAR(32) NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE user_departments (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id VARCHAR(32) NOT NULL,
  department_id VARCHAR(32) NOT NULL,
  UNIQUE KEY uk (user_id, department_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.1b conversations / messages

```sql
CREATE TABLE conversations (
  id VARCHAR(32) PRIMARY KEY,
  user_id VARCHAR(32) NOT NULL,
  agent_id VARCHAR(32) NULL,
  title VARCHAR(200) NULL,
  status ENUM('active','closed') DEFAULT 'active',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_user (user_id, updated_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE messages (
  id VARCHAR(32) PRIMARY KEY,
  conversation_id VARCHAR(32) NOT NULL,
  role ENUM('user','assistant','system') NOT NULL,
  content TEXT,
  content_type ENUM('text','card_bundle') DEFAULT 'text',
  meta JSON,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_conv (conversation_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.1c documents（入库摘要）

```sql
CREATE TABLE documents (
  id VARCHAR(32) PRIMARY KEY,
  kb_id VARCHAR(32) NOT NULL,
  title VARCHAR(255) NOT NULL,
  oss_key VARCHAR(500) NOT NULL,
  status ENUM('draft','processing','ready','published','failed') DEFAULT 'draft',
  hit_rate DECIMAL(5,4) NULL,
  created_by VARCHAR(32) NOT NULL,
  deleted_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_kb_status (kb_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.2 agents

```sql
CREATE TABLE agents (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  main_model_id VARCHAR(32) NOT NULL,
  fallback_model_ids JSON,
  current_version VARCHAR(20) DEFAULT 'v1.0',
  status ENUM('draft','testing','grayscale','formal','disabled','archived') DEFAULT 'draft',
  grayscale_ratio TINYINT DEFAULT 10,
  memory_access ENUM('none','preference','fact','all') DEFAULT 'all',
  can_modify_memory TINYINT(1) DEFAULT 0,
  created_by VARCHAR(32) NOT NULL,
  deleted_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.3 agent_configs

`config` JSON **仅允许**：`skill_ids` `kb_ids` `kg_ids` `callable_agent_ids` `prompt_template_id` `system_prompt` `variables` LLM 参数。  
**禁止**写入一等 `tool_ids` / `workflow_ids`。

### 2.4 agent_skills / agent_callable_agents

```sql
CREATE TABLE agent_skills (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  agent_id VARCHAR(32) NOT NULL,
  skill_id VARCHAR(32) NOT NULL,
  UNIQUE KEY uk (agent_id, skill_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE agent_callable_agents (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  agent_id VARCHAR(32) NOT NULL,
  target_agent_id VARCHAR(32) NOT NULL,
  UNIQUE KEY uk (agent_id, target_agent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.5 skills / skill_versions / skill_tools

```sql
CREATE TABLE skills (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  description TEXT NOT NULL,
  system_prompt TEXT NOT NULL,
  user_prompt_template TEXT,
  share_level ENUM('global','private') NOT NULL,
  risk_level ENUM('low','medium','high') DEFAULT 'low',
  approval_mode ENUM('self','role','user') DEFAULT 'self',
  approval_role_id VARCHAR(32) NULL,
  approval_user_id VARCHAR(32) NULL,
  workflow_id VARCHAR(32) NULL,
  current_version VARCHAR(20) DEFAULT 'v1.0',
  status ENUM('draft','published','disabled') DEFAULT 'draft',
  created_by VARCHAR(32) NOT NULL,
  deleted_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE skill_versions (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  skill_id VARCHAR(32) NOT NULL,
  version VARCHAR(20) NOT NULL,
  snapshot JSON NOT NULL,
  published_at DATETIME,
  UNIQUE KEY uk (skill_id, version)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE skill_tools (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  skill_id VARCHAR(32) NOT NULL,
  tool_id VARCHAR(32) NOT NULL,
  UNIQUE KEY uk (skill_id, tool_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.6 tools / tool_snapshots

工具**不版本化**（与技能故意不同）；`tool_snapshots` 保留最近 5 次。

```sql
CREATE TABLE tools (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  tool_key VARCHAR(100) NOT NULL UNIQUE,
  description TEXT NOT NULL,
  tool_type ENUM('http','builtin') NOT NULL,
  config JSON NOT NULL,
  param_schema JSON NOT NULL,
  return_schema JSON,
  risk_level ENUM('low','medium','high') DEFAULT 'low',
  enabled TINYINT(1) DEFAULT 1,
  permissions JSON,
  deleted_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.7 kb_permissions（并集鉴权）

应用层：用户本人 ∪ 任一部门 ∪ 任一角色命中即有权。  
**禁止**实现「所有部门都必须授权」的交集逻辑。

### 2.8 documents / document_qa_pairs

```sql
CREATE TABLE document_qa_pairs (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  document_id VARCHAR(32) NOT NULL,
  question TEXT NOT NULL,
  expected_chunk_hint TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_doc (document_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

文档发布前校验问答对数量（默认≥5）与命中测试召回率≥80%。

## 3. 角色种子

必须包含：`role_department_admin`，权限点示例：

- `usage.department.read`
- `user.department.read`
- `conversation.department.read_masked`
- **不含** `user.enable` `role.assign` `system.config`
